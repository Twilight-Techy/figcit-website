# Fonts

Self-hosted Latin subsets of two variable fonts, both under the SIL Open Font License 1.1:

- `figtree-latin-variable.woff2`: Figtree (headings), © The Figtree Project Authors
- `atkinson-hyperlegible-next-latin-variable.woff2`: Atkinson Hyperlegible Next (body), © Braille Institute of America

Taken from Fontsource v5.3.0. One variable file per family covers every weight the design uses.
